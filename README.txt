How it works:
1. Host this folder on any HTTPS static host (GitHub Pages, Cloudflare Pages, Netlify, Vercel, etc.).
2. Program the NFC card to open the HTTPS URL of index.html (usually just the domain).
3. On iPhone/Android, tapping the card opens the mobile-first profile.
4. Call, Email, Website, and social buttons are clickable.

Important:
- NFC itself does not store/display the webpage. It stores a URL that the phone opens.
- Use HTTPS for the production URL.
